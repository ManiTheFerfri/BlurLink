# Host Mode Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add a "host mode" to BlurLink so the host machine can forward its Blur
discovery replies to each joining player's overlay address, making joins work
when the host cannot route to the player's LAN address.

**Architecture:** A third helper session type beside `BRIDGE` and `SNIFF`. It
opens one WinDivert handle with a combined filter scoped to accepted players,
observes player introductions through that same handle (never binding a network
port), and injects one clone per matched reply while always reinjecting the
original. Players are identified by introductions carrying their overlay
address, LAN address and Blur source port; replies are matched by
(destination address, destination port).

**Tech Stack:** C++20 + WinDivert 2.2.2 (helper), .NET 8 / WPF / MVVM (app),
xUnit-style managed tests, a portable C++ test binary, PowerShell interop and
loopback scripts, CMake + MinGW g++.

**Spec:** `docs/superpowers/specs/2026-09-11-host-side-rule-design.md`

### What the driver-level runs proved (2026-09-12)

Host mode and the Join-mode bridge are now verified against a **real WinDivert
handle**, not just in logic tests. Two HIGH-severity bugs were found and fixed
by doing it, both invisible to every unelevated test because `WinDivertOpen`
fails there:

1. **The shutdown constant was an ordinal, not a bit flag** — `Stop()` could
   never stop, and the watchdog hung on the same call. See `TODO.md`.
2. **Four reinjects were taken while holding the session mutex** — a
   self-deadlock that froze the helper (unable to answer `stop`) the first time
   the bridge saw a payload it would not forward. See `TODO.md`.

It also clarified one design point by measurement: the echo backstop keys on the
IPv4 ID, and an ID of 0 means "stack, assign me one", so a genuine retransmit
always carries a fresh one. Full detail and the exact counters are in `TODO.md`.

## Global Constraints

- **No payload rewrite, ever.** Only the IPv4 destination address may change in
  a clone. Ports and payload are byte-identical. No Blur protocol constants.
- **Always reinject the original unchanged.** Host LAN behaviour must be
  identical to running without BlurLink.
- **One WinDivert handle** per helper process. **No network listener** — the
  helper never binds a UDP port; introductions are observed and reinjected.
- **One session at a time** — host mode, bridge and sniff are mutually
  exclusive; `stop` halts any of them.
- **No service, no persistence**; helper runs elevated only while started; the
  watchdog behaviour is unchanged.
- **No payloads in logs or IPC.** The logger API has no payload parameter and
  must not gain one.
- Bounded everything: roster cap **8**, player expiry **45s**, introduction
  repetition bounded and rate-limited **separately** from the clone token bucket.
- Filter is rebuilt (handle reopened) when the roster changes, **debounced**,
  and the reopen is logged.
- **There is no git repository in this checkout** (`git rev-parse` fails).
  Commit steps below are written for the normal workflow; where no repository
  exists, skip the commit and record progress in `TODO.md` instead. Do not run
  `git init` without asking.

```csharp
using BlurLink.Core.Validation;

namespace BlurLink.Core.Net;

/// <summary>
/// BlurLink's own host-introduction packet. Fixed 20-byte layout, so a value in
/// the contents can never impersonate a field (the same reasoning as the
/// existing shadow-proof JSON key lookup). Carries addresses and a port only —
/// never game, lobby or payload data.
/// </summary>
public sealed record AnnouncePacket(string OverlayIp, string LanIp, int BlurSourcePort)
{
    public const int Length = 20;
    public const byte Version = 1;
    private static readonly byte[] Magic = { (byte)'B', (byte)'L', (byte)'N', (byte)'K' };

    public byte[] Encode()
    {
        var b = new byte[Length];
        Magic.CopyTo(b, 0);
        b[4] = Version;
        b[5] = 0;
        WriteIp(b, 6, OverlayIp);
        WriteIp(b, 10, LanIp);
        b[14] = (byte)(BlurSourcePort >> 8);
        b[15] = (byte)(BlurSourcePort & 0xFF);
        return b;
    }

    public static bool TryDecode(ReadOnlySpan<byte> data, out AnnouncePacket? packet, out string reason)
    {
        packet = null;
        reason = string.Empty;
        if (data.Length != Length) { reason = "bad-length"; return false; }
        for (var i = 0; i < Magic.Length; i++)
            if (data[i] != Magic[i]) { reason = "bad-magic"; return false; }
        if (data[4] != Version) { reason = "unsupported-version"; return false; }

        var overlay = $"{data[6]}.{data[7]}.{data[8]}.{data[9]}";
        var lan = $"{data[10]}.{data[11]}.{data[12]}.{data[13]}";
        var port = (data[14] << 8) | data[15];

        if (!Ipv4Validator.TryParse(overlay, out var o) || o is null || o.Equals(System.Net.IPAddress.Any))
        { reason = "bad-overlay-address"; return false; }
        if (!Ipv4Validator.TryParse(lan, out var l) || l is null || l.Equals(System.Net.IPAddress.Any))
        { reason = "bad-lan-address"; return false; }
        if (port == 0) { reason = "zero-port"; return false; }

        packet = new AnnouncePacket(overlay, lan, port);
        return true;
    }

    private static void WriteIp(byte[] b, int offset, string ip)
    {
        if (!Ipv4Validator.TryParse(ip, out var addr) || addr is null)
            addr = System.Net.IPAddress.Any;
        addr.GetAddressBytes().CopyTo(b, offset);
    }
}
```

Note: `Encode` stays lenient so the rejection paths are reachable from tests;
`TryDecode` is the strict gate and is the only thing the host acts on.

```csharp
using BlurLink.Contracts;
using BlurLink.Core.Validation;

namespace BlurLink.Core.Net;

/// <summary>A player as the host knows them: where their Blur replies go.</summary>
public readonly record struct HostPlayerKey(string LanIp, int BlurSourcePort);

/// <summary>
/// Builds the host-mode WinDivert filter. Three terms, every one scoped to
/// accepted players, so the elevated helper is never handed traffic the feature
/// does not need.
///
/// The player's Blur source port is deliberately absent: a port mismatch must
/// be visible to the code-side matcher (and therefore reportable), not silently
/// swallowed by the filter.
/// </summary>
public static class HostFilterBuilder
{
    public static string Build(int discoveryPort, IReadOnlyList<HostPlayerKey> players)
    {
        if (discoveryPort is < 1 or > 65535)
            throw new ArgumentOutOfRangeException(nameof(discoveryPort),
                "Host mode needs a discovery port (detect it first).");

        players ??= Array.Empty<HostPlayerKey>();
        if (players.Count > BlurLinkConstants.HostMaxPlayers)
            throw new ArgumentOutOfRangeException(nameof(players),
                $"At most {BlurLinkConstants.HostMaxPlayers} players.");

        var canonical = new List<string>(players.Count);
        foreach (var p in players)
        {
            if (!Ipv4Validator.TryParse(p.LanIp?.Trim(), out var addr) || addr is null)
                throw new ArgumentException($"Invalid player address: '{p.LanIp}'.", nameof(players));
            var b = addr.GetAddressBytes();
            canonical.Add($"{b[0]}.{b[1]}.{b[2]}.{b[3]}");
        }

        var distinct = canonical.Distinct().ToArray();
        var terms = new List<string>
        {
            $"(inbound && ip && udp && udp.DstPort == {BlurLinkConstants.HostAnnounceUdpPort})",
        };

        if (distinct.Length > 0)
        {
            var srcTerms = string.Join(" || ", distinct.Select(ip => $"ip.SrcAddr == {ip}"));
            var dstTerms = string.Join(" || ", distinct.Select(ip => $"ip.DstAddr == {ip}"));
            terms.Add($"(inbound && ip && udp && udp.DstPort == {discoveryPort} && ({srcTerms}))");
            terms.Add($"(outbound && ip && udp && udp.SrcPort == {discoveryPort} && ({dstTerms}))");
        }

        return string.Join(" || ", terms);
    }
}
```

#pragma once

// BlurLink's own host-introduction packet (a BlurLink protocol value, never an
// inferred Blur one) and the host-mode filter string builder.
//
// Fixed 20-byte layout: magic "BLNK", version, flags, overlay IPv4, LAN IPv4,
// Blur source port (BE), 4 reserved bytes. Addresses and a port only — never
// payloads.

#include <array>
#include <cstddef>
#include <cstdint>
#include <string>
#include <vector>

namespace blurlink {

constexpr std::size_t kAnnouncePacketSize = 20;
constexpr std::uint16_t kHostAnnounceUdpPort = 47811;
constexpr std::size_t kHostMaxPlayers = 8;

struct AnnouncePacket {
  std::array<std::uint8_t, 4> overlay{};
  std::array<std::uint8_t, 4> lan{};
  std::uint16_t blur_src_port = 0;
};

std::vector<std::uint8_t> EncodeAnnounce(const AnnouncePacket& p);

// Strict gate: the only path the host acts on. Never throws.
bool DecodeAnnounce(const std::uint8_t* data, std::size_t len, AnnouncePacket& out,
                    std::string& reason);

// Three OR-ed terms, every one scoped to the given players. Empty error means
// success. Rejects a missing discovery port and more than kHostMaxPlayers.
std::string BuildHostFilterString(
    int discovery_port,
    const std::vector<std::array<std::uint8_t, 4>>& player_lans,
    std::string& error);

}  // namespace blurlink

#include "blurlink/announce.h"

#include <algorithm>
#include <set>
#include <sstream>

#include "blurlink/config.h"  // Ipv4ToString

namespace blurlink {
namespace {

constexpr std::uint8_t kMagic[4] = {'B', 'L', 'N', 'K'};
constexpr std::uint8_t kVersion = 1;

}  // namespace

std::vector<std::uint8_t> EncodeAnnounce(const AnnouncePacket& p) {
  std::vector<std::uint8_t> b(kAnnouncePacketSize, 0);
  std::copy(std::begin(kMagic), std::end(kMagic), b.begin());
  b[4] = kVersion;
  b[5] = 0;
  std::copy(p.overlay.begin(), p.overlay.end(), b.begin() + 6);
  std::copy(p.lan.begin(), p.lan.end(), b.begin() + 10);
  b[14] = static_cast<std::uint8_t>(p.blur_src_port >> 8);
  b[15] = static_cast<std::uint8_t>(p.blur_src_port & 0xFF);
  return b;
}

bool DecodeAnnounce(const std::uint8_t* data, std::size_t len, AnnouncePacket& out,
                    std::string& reason) {
  out = AnnouncePacket{};
  reason.clear();
  if (len != kAnnouncePacketSize) { reason = "bad-length"; return false; }
  if (!std::equal(std::begin(kMagic), std::end(kMagic), data)) {
    reason = "bad-magic";
    return false;
  }
  if (data[4] != kVersion) { reason = "unsupported-version"; return false; }

  AnnouncePacket p{};
  std::copy(data + 6, data + 10, p.overlay.begin());
  std::copy(data + 10, data + 14, p.lan.begin());
  p.blur_src_port = static_cast<std::uint16_t>((data[14] << 8) | data[15]);

  const bool overlay_zero = p.overlay == std::array<std::uint8_t, 4>{0, 0, 0, 0};
  const bool lan_zero = p.lan == std::array<std::uint8_t, 4>{0, 0, 0, 0};
  if (overlay_zero) { reason = "bad-overlay-address"; return false; }
  if (lan_zero) { reason = "bad-lan-address"; return false; }
  if (p.blur_src_port == 0) { reason = "zero-port"; return false; }

  out = p;
  return true;
}

std::string BuildHostFilterString(
    int discovery_port,
    const std::vector<std::array<std::uint8_t, 4>>& player_lans,
    std::string& error) {
  error.clear();
  if (discovery_port < 1 || discovery_port > 65535) {
    error = "discovery port out of range";
    return {};
  }
  if (player_lans.size() > kHostMaxPlayers) {
    error = "too many players (max " + std::to_string(kHostMaxPlayers) + ")";
    return {};
  }

  // Canonical, de-duplicated player addresses.
  std::set<std::string> distinct;
  for (const auto& ip : player_lans) distinct.insert(Ipv4ToString(ip));

  std::ostringstream out;
  out << "(inbound && ip && udp && udp.DstPort == " << kHostAnnounceUdpPort << ")";
  if (!distinct.empty()) {
    std::string src_terms, dst_terms;
    bool first = true;
    for (const auto& ip : distinct) {
      if (!first) { src_terms += " || "; dst_terms += " || "; }
      src_terms += "ip.SrcAddr == " + ip;
      dst_terms += "ip.DstAddr == " + ip;
      first = false;
    }
    out << " || (inbound && ip && udp && udp.DstPort == " << discovery_port
        << " && (" << src_terms << "))";
    out << " || (outbound && ip && udp && udp.SrcPort == " << discovery_port
        << " && (" << dst_terms << "))";
  }
  return out.str();
}

}  // namespace blurlink

#pragma once

// Host-mode player roster. Entries survive a player going quiet (so the
// forwards-heard diagnostic stays visible) but leave the WinDivert filter.

#include <array>
#include <cstdint>
#include <mutex>
#include <string>
#include <vector>

#include "blurlink/announce.h"

namespace blurlink {

constexpr std::int64_t kHostPlayerExpirySeconds = 45;

struct HostPlayer {
  std::array<std::uint8_t, 4> overlay{};
  std::array<std::uint8_t, 4> lan{};
  std::uint16_t blur_src_port = 0;
  std::int64_t first_seen_ms = 0;
  std::int64_t last_seen_ms = 0;
  std::int64_t forwards_heard = 0;
  std::int64_t replies_forwarded = 0;
  bool in_filter = true;
};

enum class AddResult { Added, Refreshed, RefusedCap, RefusedCollision };

class HostRoster {
 public:
  AddResult Observe(const AnnouncePacket& p, std::int64_t now_ms, std::string& note);
  void Expire(std::int64_t now_ms);
  bool NoteForward(const std::array<std::uint8_t, 4>& lan, std::int64_t now_ms);
  bool Revoke(const std::array<std::uint8_t, 4>& overlay);
  bool NoteReplyForwarded(const std::array<std::uint8_t, 4>& lan,
                          std::uint16_t blur_dst_port);
  std::vector<HostPlayer> Players() const;
  std::vector<std::array<std::uint8_t, 4>> FilterAddresses() const;
  int CountCollisions() const;

 private:
  mutable std::mutex mutex_;
  std::vector<HostPlayer> players_;
  int collisions_ = 0;
};

}  // namespace blurlink

```cpp
AddResult HostRoster::Observe(const AnnouncePacket& p, std::int64_t now_ms, std::string& note) {
  std::lock_guard<std::mutex> lock(mutex_);
  note.clear();
  for (auto& e : players_) {
    if (e.overlay == p.overlay) {           // same player re-announcing
      e.last_seen_ms = now_ms;
      e.lan = p.lan;
      e.blur_src_port = p.blur_src_port;
      e.in_filter = true;
      return AddResult::Refreshed;
    }
  }
  for (const auto& e : players_) {
    if (e.in_filter && e.lan == p.lan && e.blur_src_port == p.blur_src_port) {
      ++collisions_;
      note = "another player already uses " + Ipv4ToString(p.lan) + ":" +
             std::to_string(p.blur_src_port) + " - refusing to guess";
      return AddResult::RefusedCollision;
    }
  }
  if (players_.size() >= kHostMaxPlayers) {
    note = "player cap reached (" + std::to_string(kHostMaxPlayers) + ")";
    return AddResult::RefusedCap;
  }
  HostPlayer e{};
  e.overlay = p.overlay;
  e.lan = p.lan;
  e.blur_src_port = p.blur_src_port;
  e.first_seen_ms = e.last_seen_ms = now_ms;
  e.in_filter = true;
  players_.push_back(e);
  return AddResult::Added;
}

void HostRoster::Expire(std::int64_t now_ms) {
  std::lock_guard<std::mutex> lock(mutex_);
  for (auto& e : players_) {
    // Entry is kept so the GUI keeps its forwards-heard counter; only the
    // filter membership is dropped.
    if (now_ms - e.last_seen_ms > kHostPlayerExpirySeconds * 1000) e.in_filter = false;
  }
}
```

`NoteForward` increments `forwards_heard` for the entry whose `lan` matches and
refreshes its `last_seen_ms`; `NoteReplyForwarded` increments
`replies_forwarded` for the entry matching `lan` *and* the reply's destination
port; `Revoke` erases by overlay address (returning whether it found one);
`FilterAddresses` returns the distinct LAN addresses of `in_filter` players.

namespace {

bool IsBroadcastDst(const std::array<std::uint8_t, 4>& ip) {
  if (ip[0] == 255 && ip[1] == 255 && ip[2] == 255 && ip[3] == 255) return true;
  if (ip[0] == 0) return true;                 // 0.0.0.0 "this network"
  if (ip[3] == 255) return true;               // subnet-directed broadcast
  return ip[0] >= 224 && ip[0] <= 239;         // multicast
}

}  // namespace

HostDecision ClassifyHostPacket(const UdpPacketView& view, bool inbound,
                               int discovery_port, const std::vector<HostPlayer>& players) {
  if (inbound) return {HostAction::Reinject, {}, "inbound"};
  if (IsBroadcastDst(view.dst_ip)) return {HostAction::RefuseBroadcast, {}, "broadcast-reply"};
  (void)discovery_port;  // the filter already scopes the source port

  std::vector<const HostPlayer*> by_addr;
  for (const auto& p : players) {
    if (p.in_filter && p.lan == view.dst_ip) by_addr.push_back(&p);
  }
  if (by_addr.empty()) return {HostAction::Reinject, {}, "unmatched-address"};

  std::vector<const HostPlayer*> exact;
  for (const auto* p : by_addr) {
    if (p->blur_src_port == view.dst_port) exact.push_back(p);
  }
  // Address matched but no port did: reported so a changed reply port is
  // visible instead of being swallowed by the filter.
  if (exact.empty()) return {HostAction::Reinject, {}, "unmatched-port"};
  if (exact.size() > 1) return {HostAction::RefuseAmbiguous, {}, "ambiguous"};
  return {HostAction::Forward, exact[0]->overlay, "forwarded"};
}

## Notes for the implementer

- **Do the tasks in order.** Task 6 (the classifier) is the decision core and
  Task 8 (dispatch) is the feature; everything before them is scaffolding that
  makes them testable without a driver.
- **Never widen the filter to make something work.** If a packet is not being
  seen, the answer is evidence plus a reason string, not a broader filter. The
  whole point of the design is that the elevated helper only ever sees traffic
  aimed at accepted players.
- **If forwards are heard but replies are never captured**, check the two
  inferences in the spec §14 before changing anything: the reply's source port
  (assumed to be the discovery port) and its destination port (assumed to be the
  player's Blur source port). The `unmatched-port` reason exists precisely to
  make that visible.
- **The prerequisite is the real risk.** If the live run shows the host never
  receives the forward, host mode cannot help and the join-side alternative in
  the spec §12 becomes the likelier fix. Report that outcome rather than working
  around it.
